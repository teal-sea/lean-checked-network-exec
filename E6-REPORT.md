# E6: browser WebAssembly demo

The self-contained browser bundle (`evidence/e6-wasm/private-local-page.zip`, original acceptance filename preserved for SHA-256 continuity) runs the exact Rust engine verified in [E4](E4-REPORT.md) with the real byte-level model trained in [E5](E5-REPORT.md). It supersedes the earlier prototype, which used a different engine and synthetic byte weights.

## Try it locally

Download and unpack [the local browser bundle](evidence/e6-wasm/private-local-page.zip). From the extracted directory, run `node scripts/e6_browser_replay.js --serve 8765`, then open `http://127.0.0.1:8765/web/index.html`. Click **Generate** to complete text, or open the **mod-113** tab to run the addition check. The local server has no remote dependencies. Stop it with Ctrl-C.

## Verified results

| Check | Result |
| --- | --- |
| Fresh build | Pinned Rust 1.99.1, offline, locked dependencies and overflow checks on. A clean build from the integration source path reproduced the packaged 29,755-byte Wasm exactly. A different source path produced different bytes and embedded that path in the Wasm. Cross-path byte reproducibility is not claimed. |
| Actual browser resources | Chromium 156 fetched the exact Wasm, trained E5 model and mod-113 checkpoint recorded in the manifest. |
| Real model parity | Native Rust and Node Wasm agreed on all 5 greedy byte sequences and all 256 raw logits for the first prompt. Chromium agreed on all 256 logits for the initial prompt. With `A stitch in time`, the native and Node runs generated ` saves nine.\nThe`. |
| Rejected upload | A one-byte out-of-range change caused `load_check` to fail, disabled generation and blocked prediction and logits in Wasm. **Restore** reloaded the last approved bytes without reloading the page. Both generated bytes and logits matched the pre-rejection run. |
| Full mod-113 sweep | All **12,769 of 12,769** pairs were exact. The final ZIP took **66.70 seconds** with two workers and checked arithmetic. The first same-code successful run took 63.11 seconds. The original under-one-second target was **not met**. No lookup or unchecked build was substituted. |

The proof covers the integer Rust engine as translated to Lean, including exact logits and next-token predictions and safe handling of invalid input. The browser, compiler, wrapper, parser and sampler are outside the theorem. The browser evidence tests the integration; it does not prove the quality of the model's text or behavior on other browsers.
